Before contract

ご契約まで

  1. 01

    お問い合わせ

    LINE・お電話・フォームのいずれかでご連絡ください。「審査に落ちてしまったのですが」「まだ何も決まっていないのですが」——その一言で構いません。ご質問は無料です。些細な疑問でもお気軽にご相談ください。

    無料 / LINEは24時間受付
  2. 02

    個別相談（無料）

    専任担当者が、ご収入・ご職業・ご家族構成・ライフプランをうかがいます。そのうえで、オーダーメイドのお支払いシミュレーションをご提示。譲渡型賃貸が本当にご状況に合うのか、合わないのかも含めて率直にご説明します。

    無料 / 所要 約60〜90分 / オンライン可
  3. 03

    プラン決定

    お支払い能力をベースに「無理のないプラン」を確定します。賃料・契約期間・初期費用のバランスを、生涯コストの観点から調整します。

    賃料 / 契約期間 / 初期費用の確定
  4. 04

    物件のご紹介・内見

    ご希望条件に合う物件をご紹介します。ご希望の物件が既存の在庫にない場合は、条件に合う物件を市場からお探しし、オーナーとのマッチングを行います。注文住宅のご希望にも対応しています。

    マンション / 戸建て / 注文住宅
  5. 05

    入居審査

    金融機関による信用調査は行いませんが、毎月の賃料を継続してお支払いいただけるかを確認する弊社独自の入居審査を実施します。物件・条件により、保証会社のご利用を条件とさせていただく場合がございます。

    信用情報の照会なし / 保証会社のご利用が条件となる場合あり
Contract & After

ご契約からマイホーム取得まで

  1. 06

    ご契約（二重契約の締結）

    「定期借家契約（賃貸）」と「売買予約契約（購入）」を同時に締結します。あわせて所有権移転仮登記を設定し、将来あなたが所有権を取得する権利を保全します。物件はオーナーが現金で購入するため、住宅ローンの審査は発生しません。

    定期借家契約 + 売買予約契約 + 所有権移転仮登記
  2. 07

    ご入居 — 自由な暮らしのスタート

    壁紙の変更、キッチン改修、フローリングの張り替え。DIYもリフォームも自由です。ペットとの暮らしも実現できます。賃貸期間中の固定資産税・都市計画税はオーナーの負担です。

    ※工事内容によっては事前承諾が必要です
  3. 08

    賃貸期間中

    毎月の家賃をお支払いいただきます。契約期間中は賃料が一定のため、家計の見通しが立てやすくなります。日々の小修繕・メンテナンス費用は原則として入居者様のご負担です。ご資金の状況が好転した場合は、期間中の一括購入によって早期に所有権を取得することも可能です。

    賃料は契約期間中一定 / 一括購入による早期取得も可
  4. 09

    期間満了 — 完全な持ち家へ

    家賃を遅れなく完済いただければ、売買予約契約に基づき所有権移転登記が完了します。名実ともに、あなたの家になります。

    所有権移転登記の完了

お手続きにあたってのご注意

  • すべての方が無条件でご契約いただけるわけではありません。弊社独自の入居審査の結果、ご希望に沿えない場合がございます。
  • 長期契約のため、一定期間内での中途解約（退去）時には、違約金や原状回復に関する費用のご負担が発生いたします。契約前に条件を書面でご確認いただきます。
  • ご契約時には、宅地建物取引士による重要事項説明を実施いたします。ご不明点はその場で必ずご確認ください。
